## Ringkasan Langkah Praktikum

1. **Struktur dasar** — buat `index.html` dengan `<!DOCTYPE html>`, `<head>`, `<title>`, `<body>`.
2. **Paragraf** — tambah dua `<p>` berisi teks.
3. **Judul** — tambah `<h1>` dan `<h2>` sebagai judul & subjudul.
4. **Format teks** — pakai `<b>`, `<i>`, `<strong>`, `<em>`, `<mark>`, `<small>`, `<del>`, `<ins>`, `<sub>`, `<sup>`.
5. **Gambar** — sisipkan `<img>` dengan atribut `src`, `width`, `alt`, `title`.
6. **Ukuran gambar** — atur lewat atribut `width`/`height`.
7. **Hyperlink** — buat `<nav>` berisi link internal (`index.html`, `halaman2.html`) & eksternal (Google).
8. **List** — buat `<ul>` (Keahlian) dan `<ol>` (Urutan Belajar).
9. **Komentar** — tandai bagian kode dengan `<!-- ... -->`.
10. **Gabungan** — susun semua elemen jadi satu halaman Profil Mahasiswa.
